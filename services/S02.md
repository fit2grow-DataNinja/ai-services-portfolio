# S02 — CRM Data Quality & Freshness Auditor

**Portfolio status:** **S02 synthetic-data portfolio MVP complete and closed (2026-11-09).** Both Variant 1 (FastAPI/Open WebUI) and Variant 2 (ChatGPT Skill/Python) are complete and accepted for the defined synthetic-data scope; the portfolio comparison is complete. Neither variant is production-ready.

## Purpose
Identify reviewable CRM CSV data-quality findings using deterministic Python rules, then explain results in conversational AI. Compare two integrations against the **same synthetic business-rule scope** without conflating technical architectures.

## Technical repositories
- [Variant 1 — FastAPI + Open WebUI](https://github.com/fit2grow-DataNinja/s02-crm-data-quality-auditor) — API, Workspace Tool adapter, tests, deployment, security.
- [Variant 2 — ChatGPT Skill + Python](https://github.com/fit2grow-DataNinja/s02-crm-data-quality-auditor-skill) — Skill, Python CLI, synthetic fixtures, tests, installation and execution documentation.
- [Single S02 portfolio use-case / comparison](../case-studies/S02-crm-data-quality-auditor.md) — business scenario, recorded evidence, trade-offs and cross-variant interpretation.

The service repositories own technical implementation and detailed user instructions; the portfolio repository owns the S02 use case and comparison.

## Evidence and boundaries
The shared synthetic case reports **202 contacts, 121 deals, 92 medium missing-owner findings**. Variant 1 met 7/7 documented MVP criteria; its 11-test suite pass was user-reported. Variant 2 includes a 17-test regression suite with successful fresh-checkout execution confirmed by the owner, reported issue-level parity on the shared case, and owner-confirmed reuse by a second ChatGPT user with matching deterministic results. Evidence details and limitations are recorded in the [portfolio case study](../case-studies/S02-crm-data-quality-auditor.md) and each variant's validation record.

Both variants are **synthetic-data only**. SEC-001 is not implemented; missing-owner policy is provisional; full freshness/close-date reconciliation and missing-association inference from partial exports remain out of scope. GitHub CI and commercial hardening are deferred. Centralized Skill version/update governance and independent model-explanation fidelity verification have not been demonstrated. No customer-data or production-readiness claim.
